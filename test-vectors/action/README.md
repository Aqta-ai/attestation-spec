# ACTION-v1 conformance vectors

Deterministic test vectors for [spec/ACTION-v1.md](../../spec/ACTION-v1.md),
generated by [`generate.py`](./generate.py) from the seed
`sha256("attestation-spec/test-vectors/action-1")`.

Vector issuer public key (pin this when verifying the suite):

    pOaccW6Csyo1POtxjixPH80oux9--YC1tzzaENT4vQ0

A conformant ACTION-v1 verifier MUST return **valid: true** for every record
in `valid/` and **valid: false** for every record in `invalid/`, when invoked
explicitly for the ACTION-v1 profile with the key above pinned.

Every vector participates in the cross-implementation interop sweep. Adding a
new defect class requires both a vector here and a sweep run across both
reference verifiers before release.

## valid/

| Vector | Exercises |
|---|---|
| 001-allowed | Full record: session, intent, multi-policy, ALLOWED. |
| 002-blocked | Same shape, BLOCKED. A refusal is a first-class record. |
| 003-no-session | `session_id` and `intent_hash` both `""` (action outside a session). |
| 004-session-no-intent | Session present, no registered intent (`intent_hash` `""`). |
| 005-empty-policy | `policy_applied` is `[]`, which is permitted. |
| 006-multi-policy | Three policies, lexicographic order. |
| 007-non-ascii-tool | Non-ASCII in `tool`, signed as literal UTF-8 (§6). |
| 008-non-utc-offset | Timestamp with a `+02:00` offset instead of `Z`. |
| 009-agent-empty | `agent` is `""`: identity is caller-asserted and MAY be unclaimed. |
| 010-deep-namespace | Long dotted `tool` namespace. |

## invalid/

| Vector | MUST fail because |
|---|---|
| 001-tampered-signature | Signature bytes altered after signing. |
| 002-tampered-outcome | `outcome` flipped BLOCKED to ALLOWED after signing. |
| 003-tampered-public-key | `public_key` replaced; also fails the pin check. |
| 004-missing-field | Required field `agent` absent. |
| 005-unknown-field | Carries `cost_prevented_eur`, an ATTESTATION-v1 field; unknown fields are rejected (§4). |
| 006-integer-version | `v` is the integer `1`; ACTION-v1 requires the string `"action-1"`. |
| 007-attestation-v1-receipt | A complete, correctly signed ATTESTATION-v1 receipt. Accepting it means the verifier profile-sniffs by field shape instead of enforcing the ACTION-v1 structure (§4, §7). |
| 008-uppercase-args-hash | `args_hash` in uppercase hex; format is 64 lowercase hex chars. |
| 009-policy-not-sorted | `policy_applied` reordered after signing; also violates the sort rule. |
| 010-policy-not-strings | `policy_applied` contains a non-string member. |
| 011-timestamp-no-offset | Timestamp lacks an explicit timezone offset. |
| 012-suppressed-outcome | `SUPPRESSED` is not an ACTION-v1 outcome (§5). |
| 013-empty-tool | `tool` is `""`; MUST be non-empty. |
| 014-intent-without-session | `intent_hash` set while `session_id` is `""` (§7 semantic rule). |
| 015-escaped-unicode-signing | Signed over `\uXXXX`-escaped bytes; a §6-conformant verifier reconstructs literal UTF-8 and the signature fails. The cross-language escaping trap, pinned as a vector. |

## Regenerating

    python3 generate.py

Output is deterministic: same seed, same bytes. Re-run after any spec change
that alters canonical serialisation, and treat any diff in existing vectors as
a breaking change requiring a version decision.
