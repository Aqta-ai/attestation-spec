# policy conformance vectors (DRAFT)

Deterministic vectors for the `policy` profile in [spec/POLICY-v1.md](../../spec/POLICY-v1.md) section 8: ACTION-v1
decision records whose `policy_applied` entries bind POLICY-v1 statements by hash, the statements, and inclusion
proofs against one public head. Generated by [`scripts/make-policy-vectors.py`](../../scripts/make-policy-vectors.py)
from public seeds. The format is a draft.

Each file is `{"bundle": {...}}`. A conformant verifier, invoked explicitly with the `policy` profile and the issuer
key in [`INDEX.md`](./INDEX.md) pinned, MUST return `PASS` for `pass/`, `FAIL` for `fail/` and `INCOMPLETE` for
`incomplete/`.

`pass/003` and `fail/015` carry the same two bindings, `policy_😀` and `policy_～`, which sort one way by UTF-16 code
unit and the other by code point. `fail/004` is the backdating case: the statement's `created_at` is before the
decision, and its log leaf is after it. Every vector participates in `scripts/policy-interop-sweep.mjs`. Every key
here is a throwaway.
