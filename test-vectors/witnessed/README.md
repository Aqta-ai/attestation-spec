# witnessed conformance vectors (DRAFT)

Deterministic vectors for the `witnessed` profile in [spec/WITNESS-v1.md](../../spec/WITNESS-v1.md) section 7:
records, their inclusion proofs, and a chain of WITNESS-v1 statements that stamp the public log's head with a time
the issuer does not control. Generated by [`scripts/make-e79-vectors.py`](../../scripts/make-e79-vectors.py) from
public seeds. The format is a draft, and its Ed25519 statement stands in for a Sigstore-anchored countersignature it
does not verify (spec section 2).

Each file is `{"witness_keys": [...] | null, "tolerance_seconds": <int>, "bundle": {...}}`. A conformant verifier,
invoked explicitly with the `witnessed` profile, the issuer key in [`INDEX.md`](./INDEX.md) pinned and those
parameters, MUST return `PASS` for `pass/`, `FAIL` for `fail/` and `INCOMPLETE` for `incomplete/`.

`pass/002` and `fail/002` sit one microsecond either side of the tolerance. The vector
`transparency/adversary/a3-lag-is-not-backdating` is unchanged: absence from an unwitnessed head is still not
evidence. Every vector participates in `scripts/e79-interop-sweep.mjs`. Every key here is a throwaway.
